# MyoSim R2.4 — Hardware Twin Implementation and Closure Report

**Date:** 2026-10-06  
**State:** `ENGINEERING CANDIDATE — NOT PUBLIC RELEASE` (`0.1.6.dev0`)

## Scope

R2.4 adds an opt-in software-only actuator abstraction between the safety-limited controller and physics backend. The bounded engineering question is how the existing intent-to-task pipeline responds to declared actuator delay/response assumptions and deterministic fault windows. Closure work included behavior-focused validation tests and narrowly scoped replay-import, typing, and test-expectation corrections discovered by the gates. No feature, architecture, physics-model behavior, input, or protocol scope was changed.

The Hardware Twin models fixed command delay, first-order position response, coordinate/rate limits, command dropout, stuck-actuator windows, emergency-stop queue clearing, and a per-tick trace. Bundled profile parameters are assumptions, not identified physical-device measurements. The ordinary baseline path remains the default.
