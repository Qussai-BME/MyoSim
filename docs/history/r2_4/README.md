# R2.4 Hardware Twin — Pre-release Engineering Record

These two reports document the engineering closure of the Hardware Twin milestone
(R2.4) as it stood on 2026-10-06, before it was folded into the public `0.1.6`
release together with the R2.3 real-data integration.

- Status labels inside them (for example, "engineering candidate") describe that
  pre-release moment and are kept unchanged as a dated record.
- The measured results quoted in them were produced in the author's own
  environment (CPython 3.11, MuJoCo 3.15.0, PyBullet 3.2.7). The current release
  evidence is listed in `RELEASE_NOTES_0_1_6.md`.
- Scientific boundaries stated there still apply: the actuator profiles are
  assumed, not identified; nothing here is hardware-in-the-loop, calibration
  evidence, clinical validation, or a safety case.
