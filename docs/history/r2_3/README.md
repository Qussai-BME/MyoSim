# R2.3 Historical Baseline Index

R2.3 is a **closed baseline**. It was closed on 2026-10-05 as a local release archive and was not deposited separately; its code and evidence ship as part of MyoSim 0.1.6 (the previous public release is 0.1.5.3). The canonical closure record is [`R2.3_FINAL_CLOSURE_REPORT.md`](R2.3_FINAL_CLOSURE_REPORT.md), copied byte-for-byte from the finalized R2.3 project tree. The authoritative machine-readable evidence is retained under [`artifacts/r2_3_real_emg/`](../../../artifacts/r2_3_real_emg/) at the project root.

The neighboring files in this directory (`R2.3_HANDOFF.md`, `R2.3_REAL_EMG_MYOSIM_FINAL_REPORT.md`, `R2.3_NEXT_ACTION.md`, and `R2.3_RELEASE_NOTES.md`) are historical project-document snapshots carried for traceability. Some predate the final R2.3 closure; they are not represented as canonical or byte-identical records and are not the source of current R2.4 status. Use the canonical report and root release manifest for R2.3 final claims; use the [R2.4 closure report](../r2_4/R2.4_CLOSURE_REPORT.md) and the [release verification directory](../../../artifacts/release_0_1_6_verification/) for current status and environment results.

The root-level [`artifacts/FLAGSHIP_GATE_DB7_S21.md`](../../../artifacts/FLAGSHIP_GATE_DB7_S21.md) is a frozen R2.3 contemporaneous gate record. Its CPython 3.12/PyBullet note describes the R2.3 validation environment only; it is not the R2.4 environment record. The R2.3 release manifest and verification JSON likewise retain their original R2.3 run environment and must be interpreted historically. Current dual-backend results are in the verification directory linked above.

No R2.3 prediction rows, selected S21 interval, MuJoCo result, release manifest or historical status record was changed during the R2.4 work. The archive hash and the exact protected-file comparison are recorded in the [R2.4 closure report](../r2_4/R2.4_CLOSURE_REPORT.md). Where the frozen R2.3 documents in this directory say "published", they refer to the closed archive, not to a Zenodo deposit.
